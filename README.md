# QuantumForge RAG Bot

Учебный проект по разработке RAG-бота для корпоративной базы знаний QuantumForge Software.

## Цель

Создать прототип интеллектуального помощника, который отвечает на вопросы сотрудников на основе корпоративной документации, помогает быстрее находить знания и выявлять пробелы в документации.

## Основной стек

- Python 3.11
- LangChain
- FAISS
- FastAPI
- Docker / Docker Compose
